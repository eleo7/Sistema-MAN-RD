# Recursos institucionais

Coloque o logo oficial em `assets/logo.png`. Não foi fornecido no repositório inicial. Também pode ser enviado pelo formulário sem gravá-lo no servidor.

Para usar a fonte exata no PDF, coloque cópias licenciadas de Times New Roman em `assets/fonts/times.ttf` (regular) e `assets/fonts/timesbd.ttf` (negrito), e reinicie a aplicação. Não são distribuídas fontes proprietárias neste projeto.
